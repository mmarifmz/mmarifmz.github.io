# mmarifmz public projects

This repository publishes a privacy-safe portfolio and project catalogue for
[mmarifmz](https://github.com/mmarifmz). It contains no application source,
credentials, environment configuration, tenant records, pupil information, or
private operational evidence.

## Live portfolio

Visit [mmarifmz.github.io](https://mmarifmz.github.io/) for every public
repository, presented as a case study with its objective and practical benefit
for developer communities.

Live experiences are labelled separately from source-only repositories. Demos
use synthetic or public-safe material and do not claim production execution.
